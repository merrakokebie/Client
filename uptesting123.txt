The only thing stopping the re-close is 
the inner guard — IF((@LPC <> @LDP) AND (@LDP > @LPC)) — 
which blocks it because LastPeriodClosed is 
now Sep 30 and the parameter is also Sep 30.

IF (DAY(@LDP) = 1) BEGIN
    DECLARE @PriorPeriodEnd DATETIME = DATEADD(day, -1, @LDP);
    DECLARE @AlreadyClosed  DATETIME;

    SELECT @AlreadyClosed = LastPeriodClosed
    FROM Originator WHERE OriginatorID = @ID;

    IF (@AlreadyClosed IS NULL OR @AlreadyClosed < @PriorPeriodEnd)
        EXECUTE dbo.up_ProcessMonthEndDataV2 @PriorPeriodEnd, @ID, @UserName;
END
